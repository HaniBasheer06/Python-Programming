# Python Lab Exercises

Solutions for two Python lab sheets, organized by folder.

## Lab1-Python-Basics
- `lab1_basic_program.py` — Basic Python program (I/O, print statements)
- `lab2_variables_operators_io.py` — Variables, operators, and input/output
- `lab3_calculator_area.py` — Simple calculator + area calculation programs
- `miniproject_unit_converter_bill_generator.py` — Mini project: unit converter & bill generator (both included)

## Lab2-Python-Intermediate
- `lab1_number_guessing_game.py` — Number guessing game
- `lab2_prime_factorial.py` — Prime number check + factorial
- `lab3_fibonacci_recursion.py` — Fibonacci series using recursion
- `miniproject_otp_grading.py` — Mini project: OTP generator & student grading automation (both included)

## Running

Each file is standalone:

```bash
python3 Lab1-Python-Basics/lab1_basic_program.py
```
